## Strong candidates (after v1)

- Carpool / rides board
- Gear locker
- Member directory (beyond basic roster)
- Birthdays & milestones
- Trip packing lists
- Photo / memory dump
- Idea inbox for new modules

## Explicit non-goals (for now)

- Replacing the group chat entirely
- Heavy social feed / algorithmic ranking
- Public discovery (invite-only only)
- Standalone top-level Funds tab (funding is activity-scoped)
